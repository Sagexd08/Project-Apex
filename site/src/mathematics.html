Notation and status

d is the vector dimension, P the next power of two at or above d, n the corpus size, k the result size, q a query and x a stored vector, both of unit length. s(q,x) = ⟨q,x⟩ is cosine similarity.

Statuses: Proved under stated assumptions, Measured in the saved results, Proposed otherwise. Derivations are first order. Nothing here is a comparison with another system.

Why a bit can rank neighbours

For unit vectors, ranking by inner product is ranking by angle. Take a random hyperplane with normal g. Its sign bits for q and x differ exactly when the hyperplane separates them, with probability θ/π (Goemans–Williamson). With d independent hyperplanes the Hamming distance H is Binomial(d, θ/π):

θ̂ = π · H / d E[θ̂] = θ std(θ̂) = π · sqrt( p(1−p) / d ), p = θ/π std(cos θ̂) ≈ sin θ · std(θ̂)

A one-bit code is sharpest for near neighbours and blurriest for unrelated vectors, which is exactly where sharpness is needed. The error shrinks as 1/√d. Caution: the first plane of the multibit quantizer is the sign bit, but the variance formula above is for independent random hyperplanes. Applying it to the multibit code needs a separate derivation, and it is on the loophole list.

Rotation

If R is Haar-random and x is a unit vector, each coordinate of Rx has density proportional to (1−t²)^((d−3)/2), mean 0 and variance 1/d, close to N(0,1/d) for large d. The distribution of Rx does not depend on x, which is why the quantizer needs no training.

rotate(x): z = zero_pad(x, P) repeat 3 times: z = z ⊙ D_r ; z = FWHT(z) / √P # D_r: seeded ±1 diagonal

Each round is orthogonal, so the norm is preserved. Three rounds are a standard approximation of a Haar rotation; that approximation is an assumption of the analysis. A random rotation does not make quantization error independent of the data in every sense. Heavy-tailed coordinates and clipping still matter.

Nested quantizer and its error

With clip constant C = 3 and s_c = C/√P, the 4-bit index of a rotated coordinate is clamp(floor((z + s_c)/Δ_4), 0, 15) with Δ_4 = 2s_c/16. The b-bit index is its top b bits, and nesting holds because Δ_b = 2^(4−b) Δ_4.

ε_b = ŝ_b − s = Σ_i (Rq)_i · e_i, e_i = recon_b(z_i) − z_i Var(ε_b) ≈ Δ_b² / 12 = C² / (3P · 4^b) σ_b ≈ C / ( √(3P) · 2^b )

For P = 256 and C = 3 the formula gives σ₁ ≈ 0.054, σ₂ ≈ 0.027, σ₄ ≈ 0.0068. A first prototype reported 0.0576, 0.0272 and 0.0069; that run has no saved artifact, so treat it as reported, not reproduced. Each added plane halves the error, and the error depends on P, C and b, not on the data. The estimate is slightly biased toward zero; a residual sign bit (the QJL step in TurboQuant) would remove that, and Prism v0 does not include it.

The pruning gate

Let t be the true k-th best score and τ_j the k-th best estimate at stage j. Keep a candidate if ŝ_j(c) + zσ_j ≥ τ_j − zσ_j.

Lemma, proved under its assumption

If at stage j every true top-k item and one witness item have error at most zσ_j in absolute value, no true top-k item is dropped.

Proof. At least k candidates have estimate at least τ_j. Fewer than k items have true score above t, so one of those k, call it w, has s(w) ≤ t. Then τ_j ≤ ŝ_j(w) ≤ s(w) + zσ_j ≤ t + zσ_j. For a true top-k item c, ŝ_j(c) ≥ s(c) − zσ_j ≥ t − zσ_j ≥ τ_j − 2zσ_j, which is the gate condition. ∎

The lemma is conditional. A union bound over S stages and k + 1 items, with sub-Gaussian error, gives a failure probability of at most (k+1)·S·2·exp(−z²/2), so a budget δ needs:

z ≥ √( 2 ln( 2 (k+1) S / δ ) ) k = 10, S = 3, δ = 0.01 → z ≈ 4.2
Open problem

The provable z (above 4) costs most of the saving that an empirical z of 2 to 3 gives. Measured tails over 20 million pairs per set were close to Gaussian but reached 5.2 to 7.1 standard deviations, so zero misses over every pair needs z near 7.1. A per-vector bound in the style RaBitQ derives is the likely route. Until it exists, the correct statement is: the gate is empirically calibrated and its miss rate is measured, not guaranteed.

Cost model and floor

B = n·m_1 + n_1·m_2 + n_2·m_3 bits per query, incremental planes B_prefix = n·b_1 + n_1·b_2 + n_2·b_3 if each stage re-reads its whole prefix n_j ≈ k + n · g(t) · 2 z σ_j first-order survivor count

Here m_j = b_j − b_{j−1} and g(t) is the density of similarities at the threshold. Each extra bit halves the excess over k, but only while the window 2zσ_j is small compared with how fast g changes; at one bit the formula overestimates. With one bit read per vector in stage 1, B ≥ n: Prism accelerates a scan, it does not remove it.

What is not proved

  • Floating-point rounding can invalidate a supposedly safe bound; tie handling at the threshold is by ascending id but has no adversarial test yet.
  • Squared-L2 and cosine need their own derivations; the formulas above are for inner product on unit vectors.
  • Non-power-of-two dimensions rely on zero padding, and its effect on the error formula is unmeasured.
  • The variance formula for independent hyperplanes is not shown to hold for the structured rotation's correlated coordinates.
