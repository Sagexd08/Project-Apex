Where we lose

  • Single-client speed. hnswlib is 1.64x to 1.79x faster than Bat DB at the same recall on this run. We are working on it; it is the main thing a leaderboard such as ann-benchmarks measures.
  • Build time. Bat DB built the index in 41.6 s, hnswlib in 28.1 s (1.48x slower). Bat DB built single-threaded in this harness.

Caveats

  • Bat DB and hnswlib run in-process. Qdrant is a server reached over HTTP, so its latency includes the network stack. Compare Bat DB with hnswlib for engine speed, and with Qdrant for end-to-end behaviour.
  • One machine, synthetic-free public data, 3 repetitions. No claim here is a ranking on ann-benchmarks or VectorDBBench.
  • Raw files: Bat DB (Atlas), hnswlib, Qdrant, run configuration.
