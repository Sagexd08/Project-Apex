What’s done

Give an agent a memory. Watch it use it.

Five steps: write decisions, ask a question, change a decision, ask what you believed before, and prove another tenant sees nothing. Click any call to see its request and response.

This page is a JavaScript simulation of the memory API with a toy 64-dimension embedder, so you can try the idea with nothing installed. It is not the Rust engine and its latencies mean nothing. The real engine serves a live playground at /playground when you run atlas-cli.

Press Play 40s demo for a narrated walk-through, or drive it yourself.
